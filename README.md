# 城市公共设施服务平台

基于AI视觉识别的城市公共设施报修与治理服务平台，致力于提高城市公共设施的管理效率和服务质量，为市民创造更美好的生活环境。

## 项目功能

### 核心功能
- **AI智能报修**：通过上传图片，AI自动识别设施类型和损坏类型
- **报修管理**：用户可以查看和管理自己的报修记录
- **用户中心**：个人信息管理、历史报修记录查询
- **地图集成**：在地图上选择具体位置，提高位置信息的准确性
- **通知系统**：实时通知报修处理进度和系统消息

### 技术特点
- **前端**：HTML5、CSS3、JavaScript、响应式设计、动画效果
- **后端**：Python、Flask、SQLite、JWT认证
- **AI识别**：基于图像处理和关键词匹配的智能识别
- **数据库**：优化的数据库模型，添加了索引提高查询性能
- **安全性**：JWT token认证，密码加密存储

## 快速开始

### 环境要求
- Python 3.7+
- Flask 2.0+
- 浏览器（Chrome、Firefox、Edge等）

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd AI-city-public-service-platfom
   ```

2. **安装后端依赖**
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. **启动后端服务**
   ```bash
   python app.py
   ```

4. **访问前端页面**
   打开浏览器，访问 `http://localhost:5000`

## 使用说明

### 1. 注册/登录
- 点击页面右上角的"登录/注册"按钮
- 填写手机号和密码进行注册
- 注册成功后自动登录

### 2. AI智能报修
- 点击"AI智能报修"菜单
- 上传设施损坏的图片
- 点击"开始AI识别"按钮
- 系统自动识别设施类型和损坏类型
- 填写详细信息并提交

### 3. 查看报修记录
- 登录后点击"用户中心"
- 在"我的报修记录"中查看所有报修申请
- 点击"查看详情"查看具体信息
- 对于待受理的报修，可以点击"撤销申请"

### 4. 地图位置选择
- 在提交报修时，点击"在地图上选择位置"
- 在地图上点击选择具体位置
- 系统自动填充地址信息

### 5. 通知中心
- 在用户中心点击"通知中心"
- 查看系统通知和报修进度更新
- 点击通知标记为已读

## 技术文档

### 数据库设计
- **User表**：用户信息
- **Repair表**：报修记录
- **Admin表**：管理员信息
- **Notification表**：通知记录

### API接口
- **用户相关**：注册、登录、获取个人信息、更新个人信息
- **报修相关**：提交报修、获取报修列表、获取报修详情、删除报修
- **通知相关**：获取通知列表、标记通知已读、获取未读通知数量
- **管理员相关**：登录、获取所有报修、更新报修状态

### AI识别原理
1. 提取图片特征
2. 与设施类型和损坏类型的关键词库进行匹配
3. 计算匹配度，返回识别结果

## 项目亮点

1. **AI智能识别**：减少用户手动输入，提高报修效率
